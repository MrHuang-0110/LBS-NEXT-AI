MDK 编译后 USB 固件升级（与 APP 项目相同流程）

1. Keil：Options for Target -> User -> After Build
   - Run #1: fromelf.exe --bin -o "$L@L.bin" "#L"
   - Run #2: python -u "..\..\tools\mdk_deploy_prompt.py" "#L"

2. 串口：编辑本目录 deploy_port.txt 第一行，例如 COM30

3. 编译成功后弹出「是否通过 USB 升级到设备？」
   - 选「是」：Ymodem 发送 Output\atk_f103.bin
   - 选「否」：仅完成编译

PikaPython 脚本下发:
  python lbs_fw_update.py deploy main.py -p COM30
  需 rust-msc-latest-win10.exe，默认查找顺序:
    APP2/tools/  ->  APP2/Middlewares/pikapython/  ->  ../APP/Middlewares/pikapython/
  或设置环境变量 PIKA_COMPILER=完整路径

依赖: pip install pyserial
